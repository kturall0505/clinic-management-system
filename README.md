# clinic-management-system
🏥 Tibb Klinika İdarəetmə Sistemi

## Texniki Yığın
- **Frontend:** Flutter (Dart) — Windows, Web, iOS, Android
- **Backend:** Supabase (PostgreSQL)
- **Auth:** Supabase Auth
- **Storage:** Supabase Storage
- **Push Notifications:** Firebase Cloud Messaging
- **Ödəniş:** Stripe / Lokal ödəniş

## Xüsusiyyətlər
- Offline-first (lokal SQLite + bulud sinxronizasiyası)
- Multi-tenancy (Row Level Security)
- Daxili AI köməkçisi
- Təhlükəsizlik və uyğunluq
